# @vilancer/scribble

FaceTime-style drawing for React Native video calls: `ScribbleProvider` (one annotation session per
call), `ScribbleOverlay` (the ink layer over a video), `ScribbleToolbar` (pen, marker, pencil,
crayon, shapes, colours, sizes) and transport providers (`jitsi(conference)`, `MemoryTransport`).

Peers: `react`, `react-native`, `react-native-svg`, `react-native-gesture-handler`,
`react-native-reanimated`. See the [repository README](../../README.md) for setup and usage.
